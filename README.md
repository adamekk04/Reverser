# Reverser
Reverser is a Minecraft Fabric mod that is made to help reverse engineer world generation process

> NOTE! This mod is not made for servers with players. It can lag your server.

## Versions
| Mc Version | Include Snapshots | Mod version |
|-|-|-|
| 26.3 | No | 0.1 |

## Building from source
1. Clone this repository
2. Run `./gradlew build`
